# Pumpilot Firmware — 睿昇胰岛素泵泵体固件

上海旭润医学 · 一次性贴敷式胰岛素泵 **泵体固件**（nRF52832 MCU）。

> 本仓库为**泵体固件**，与控制器 APP（[`benxi809/pumpilot`](https://github.com/benxi809/pumpilot)）通过 BLE(IEEE 11073) 对接，是独立交付物。两仓库协同以《接口边界与契约文档》为唯一对接基准。

## 定位
- 固件运行于一次性贴敷式胰岛素泵的 nRF52832 MCU；
- 负责**输注执行**（微型步进电机 PWM 驱动、基础率/大剂量调度）、**状态监测**（滑动格栅药量、霍尔反馈、电池）、**报警上报**、**BLE 通信与绑定**、**时钟**、**出厂信息**、**低功耗**。
- 权威算法参数：**每脉冲 0.00339 IU**。

## 技术与工具链
- MCU：Nordic nRF52832
- SDK：nRF5 SDK / nRF Connect SDK (Zephyr)
- 编译器：ARM GCC / Keil
- 调试：J-Link + RTT / nRF Connect 抓包
- 单元测试：Unity / CMock

## 对接
APP 侧使用 `SimulatorTransport`（模拟固件行为）先行联调；本仓库实现真实 BLE 服务后与 APP 做真实联调与协议一致性验证。
