# Pumpilot 固件 设计评审记录

**项目名称**：Pumpilot — 睿昇胰岛素泵泵体固件（nRF52832）
**文档版本**：v1.0
**评审类型**：固件详细设计评审（FW-D1~FW-D3 阶段）
**评审日期**：2026-08-04
**评审对象**：《固件详细设计说明书 v1.0》《固件数据库详表 v1.0》《固件完整API与BLE通讯协议文档 v1.0》《固件模块流程图 v1.0》

---

## 1. 评审目的

对固件详细设计进行评审，确认设计已实现固件需求（FW-SRS）、可实施、具备可测试性并满足医疗安全要求，识别并消除设计缺陷。

## 2. 评审小组

| 角色 | 评审关注点 |
|------|-----------|
| 产品/需求 | 需求完整性、是否偏离 FW-SRS 与权威需求文档 |
| 固件开发 | 可实施性、模块/接口/HAL设计合理性 |
| APP/软件 | 与 APP 接口契约、命令/上报帧一致性 |
| 测试/质量 | 可测试性、覆盖 FW-SVTP |
| 安全/法规 | 医疗安全、输注防叠加、确认合规 |

## 3. 评审范围与依据

- 固件 4 层架构（app/services/drivers/hal+stack）；
- 泵状态机与转换；
- 基础率/大剂量/临时基础率调度算法；
- 格栅蛇形药量映射；
- 报警分级；
- BLE/IEEE 11073 agent 协议；
- 闪存存储布局；
- 对照：FW-SRS、《接口边界与契约文档》、权威需求文档。

## 4. 评审结论

> **结论：条件通过。**
> 设计完整可实现，无阻塞性问题。存在 **3 项重要问题** 需在编码前关闭，若干一般问题记录跟踪。

## 5. 重要问题（必须关闭）

| 编号 | 问题 | 影响 | 建议 |
|------|------|------|------|
| FDR-01 | **BLE GATT 实际 UUID 未实机确认**：采用 IEEE 11073 标准（180F/2A20/2A21），但厂家 nRF52832 实机固件可能用私有 UUID | 联调不匹配 | FW-D3 前用 nRF Connect 实机抓包确认；未确认前按本契约实现 |
| FDR-02 | **复合大剂量双波切换时序**（防叠加）仅描述思路，缺具体"切换点等待 pulse_busy=0 + 缓冲清空"的定时校验伪码 | 输注安全 | 补齐切换点时序与防叠加状态细化 |
| FDR-03 | **FlashStore 分区地址为建议值**，需以最终链接脚本(.ld)与 SoftDevice 保留区为准，防止覆盖协议栈 | 固件无法启动 | 链接时核对分区，出厂信息区写保护 |

## 6. 一般问题（跟踪）

| 编号 | 问题 | 处置 |
|------|------|------|
| FDR-04 | 上报帧格式建议（§7）与 IEEE 11073 APDU 并存，需在联调时确定统一走 notify 载荷 | 联调阶段定 |
| FDR-05 | 基础率余量匀距分配的具体周期（跨 3 分钟槽对齐）需细化 | 编码时细化 |
| FDR-06 | 日志环形缓冲容量需按实际 Flash 寿命评估 | FW-D4 优化 |
| FDR-07 | 霍尔校验的"连续10脉冲"计数需与 PWM 同步锁存 | 编码注释 |
| FDR-08 | 电池旁路（ON/BYP）切换时机需定义进入/退出条件 | 补充 |

## 8. 可测试性评估

- 算法：脉冲换算/格栅映射/调度可 PC 单元测试（Unity/CMock）；
- 状态机：合法/非法转换用例可测；
- HAL 驱动：板载 JTAG + 逻辑分析仪；
- BLE/协议：nRF Connect 抓包 + 协议一致性验证；
- 报警阈值：可注入模拟电压/信号测试分级。
