# Pumpilot 固件确认测试计划 (FW-SVTP)

**项目名称**：Pumpilot — 睿昇胰岛素泵泵体固件（nRF52832）
**文档版本**：v1.0
**编制日期**：2026-08-04
**依据文档**：《固件软件需求说明书(FW-SRS) v1.0》《接口边界与契约文档 v1.0》《胰岛素泵控制PCBA与固件开发需求》
**测试目标**：验证固件是否满足 FW-SRS 需求，确认输注精度、安全报警、通信契约的正确性。

---

## 1. 目的与范围

### 1.1 目的
确认泵体固件软件功能、输注精度、报警处理、通信行为符合已批准需求，保障胰岛素输注的安全有效。

### 1.2 范围
- 输注执行（基础率/大剂量/脉冲调度）、状态监测、报警、BLE 通信、时钟、出厂信息、低功耗。

### 1.3 测试环境
| 项 | 配置 |
|----|------|
| 平台 | 固件目标板（nRF52832 泵体 PCBA） |
| 工具 | J-Link + RTT / 串口日志 |
| 泵台架 | 泵机械台架（模拟格栅/霍尔/进针） |
| APP 侧 | Pumpilot APP 或 SimulatorTransport 对接 |
| 抓包 | nRF Connect / BLE sniffer 核对 IEEE 11073 帧 |
| 测量 | 输注量精度测量（电子天平/剂量计） |

---

## 2. 测试策略与优先级

| 优先级 | 对象 | 策略 |
|:------:|------|------|
| P0（必测） | 输注精度、报警(一/二/三级)、机械故障/堵塞、电池耗尽 | 全场景+异常+边界 |
| P1 | 基础率/大剂量调度、格栅药量、BLE 绑定 | 全场景 |
| P2 | 时钟对时、出厂信息、日志、低功耗 | 主场景 |

### 完成准则
1. P0 全部通过，无未决严重缺陷；
2. 全用例通过率 ≥ 98%；
3. 输注精度在允差内；
4. 协议一致性通过。

---

## 3. 测试用例设计

### 3.1 输注执行 (DRIVE)
| 用例 | 关联需求 | 关键测试点 |
|------|----------|------------|
| FW-TC-DRIVE-01 | FW-DRIVE-01 | PWM1/PWM2 20ms 脉冲序列、间隔 30ms 波形正确 |
| FW-TC-DRIVE-02 | FW-DRIVE-02 | 基础率 48 段调度；每 3 分钟脉冲；段脉冲数 = 流速×0.5/0.00339 |
| FW-TC-DRIVE-03 | FW-DRIVE-02 | 小流速时均匀间隔分配 |
| FW-TC-DRIVE-04 | FW-DRIVE-03 | 快速大剂量脉冲数 = 剂量/0.00339 一次连续 |
| FW-TC-DRIVE-05 | FW-DRIVE-03 | 扩展大剂量定时分布 |
| FW-TC-DRIVE-06 | FW-DRIVE-03 ★ | 复合大剂量前半 bolus 后半基础率，切换无脉冲叠加 |
| FW-TC-DRIVE-07 | FW-DRIVE-04 | 最小增量 0.01 IU/h；边界输入 |

### 3.2 状态监测 (SENSE)
| 用例 | 关联需求 | 关键测试点 |
|------|----------|------------|
| FW-TC-SENSE-01 | FW-SENSE-01 | 格栅**蛇形物理排列**映射正确（序号1=K7=0ml→序号64=K57=2ml）；K7 用尽、K1 药量低；**断言不同格号位置用药量换算无误** |
| FW-TC-SENSE-02 | FW-SENSE-02 | 霍尔信号检测；连续10脉冲无信号→机械故障 |

| FW-TC-SENSE-04 | FW-SENSE-04 | 电池电压阈值：<1.8V 耗尽、<2.0V 电量低 |

## 4. 执行与环境搭建

- 台架测试：以模拟泵台架（格栅/霍尔/进针）驱动固件，验证输注与监测；
- 联调测试：接入 Pumpilot APP 做端到端验证；
- 测量：电子天平称量实际输注量，校验 0.00339 IU/脉冲 精度。
