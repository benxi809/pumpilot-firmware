**项目名称**：Pumpilot — 睿昇胰岛素泵泵体固件（nRF52832）
**文档版本**：v1.0
**编制日期**：2026-08-04
**依据文档**：《固件软件需求说明书(FW-SRS) v1.0》《接口边界与契约文档 v1.0》《胰岛素泵控制PCBA与固件开发需求》

## 1. 硬件平台

| 项 | 规格 |
|----|------|
| MCU | Nordic nRF52832（BLE 5） |
| 电源 | CR1225 纽扣电池，工作电压 ~2.0V，容量 50mAh，目标工作 2 周 |
| 驱动 | PWM1(针6)、PWM2(针7) 轮流驱动微型步进电机线圈 |
| 蜂鸣器 | 针5 (beep) |
| 滑动格栅 | 8×8 开关矩阵（针8~12,23,27,28 行 + 针15~22 列），K1~K64 |
| 霍尔 | 针24 霍尔信号检测 |
| 针到位 K65 | 针4 (ZLCD1) |
| 丝杆锁止 K66 | 开关量 |
| 电源旁路 | 针37 (ON/BYP)，电压<2.0V 进旁路模式 |
| 时钟 | 连续时钟 RTC，日误差 ≤1s |

└───────────────┬───────────────────────────┬──────────────────┘
                │                           │
┌───────────────▼───────────────────┐  ┌────▼─────────────────────────┐
│      业务/服务层 (Service)          │  │   协议栈层 (Stack)             │
│   BasalScheduler · BolusScheduler  │  │  IEEE11073 Service (agent)    │
│   ReservoirMonitor · AlarmEngine   │  │  BLE GATT 180F (2A20/2A21)   │
│   ClockMgr · FactoryInfo           │  │  SoftDevice / nRF SDK         │
└───────────────┬───────────────────┘  └─────────┬────────────────────┘
                │                                │

│                驱动/HAL层 (Driver/HAL)                           │

                                │
                        ┌───────▼───────┐

                        └───────────────┘

| 层 | 职责 | 关键模块 |

## 3. 核心状态机（固件）

依据权威需求「泵的基本工作过程」设计：

```
仓储(深睡) --灌注唤醒--> 初始休眠 --连接/绑定--> 初始化中
   ↑                           │
   │                           ▼
   └─贴敷+启用              就绪(等待)
                                │ 开始输注
                                ▼
                       ┌──►  运行中 (基础率/大剂量/临时基础率)
                       │        │
                       │◄──暂停/恢复  │ 废止
                       │        ▼
                       └─── 治疗暂停   废止(终止)
```

**关键过程**：
1. **仓储状态**：MCU 深睡，格栅接触簧片位于 K3；灌注时推杆回退触发中断唤醒；
2. **排空初始化**：贴敷后进针（K65 到位），PWM1/PWM2 输出排空；直到 K66 锁止 → 就绪；
3. **输注**：每 3 分钟执行一次基础率脉冲；大剂量按类型执行。

## 4. 模块设计

### 4.1 输注控制模块
- **BasalScheduler**：48 段基础率定时间片调度；3 分钟周期唤醒输注；不足匀距。
- **BolusScheduler**：快速/扩展/复合大剂量脉冲分配，双波切换去重。
- **PulseDriver**：PWM1/PWM2 20ms 脉冲序列输出 + 霍尔校验（连续10脉冲无信号→机械故障）。

### 4.2 药量监测模块
- **GridScanner**：8×8 滑动格栅扫描，识别当前物理位置（注：格栅**非按编号顺序排列**，须用蛇形/Z字物理次序表 K7,K6,...,K57 做位置索引）；
- **ReservoirMonitor**：按物理排列序号→药量线性映射（序号1=K7=0ml → 序号64=K57=2ml）；K7 用尽、K1 药量低（K1 物理位置在 0ml 端第 7 位）。

### 4.3 报警模块
- **AlarmEngine**：分级（一/二/三）报警检测与上报；
- **BeeperDriver**：按警报类型输出蜂鸣/震动模式（一级持续、二级断续30s循环、三级3次循环）。

### 4.4 通信模块
- **BleService**：GATT Service 180F、Char 2A20/2A21，绑定鉴权、定向广播恢复；
- **Ieee11073Service**：agent 对象模型，命令接收/校验/回执，数据上报。

### 4.5 时钟模块
- **ClockMgr**：RTC，首次绑定由 APP 设置时间，每小时对时。

### 4.6 出厂信息模块
- **FactoryInfo**：存储唯一序列号、型号、批号、有效期、结构信息、固件版本。

### 4.7 日志模块
- **LogManager**：工作状态存储，蓝牙导出。

### 4.8 电源管理模块
- **PowerMgr**：深睡/唤醒管理；<2.0V 旁路；低功耗调度。
