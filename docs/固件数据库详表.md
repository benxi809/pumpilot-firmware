# Pumpilot 固件数据存储详表（闪存布局）

**项目名称**：Pumpilot — 睿昇胰岛素泵泵体固件（nRF52832）
**文档版本**：v1.0
**编制日期**：2026-08-04
**存储介质**：nRF52832 内部 Flash（512KB，4KB/页）
**存储机制**：nRF FDS（Flash Data Storage）抽象，键值(key/value)记录，掉电保护
**依据**：《固件架构与概要设计 v1.0》《接口边界与契约文档 v1.0》《固件软件需求说明书(FW-SRS) v1.0》

---

## 1. 存储分区总览

| 分区 | 起始(建议) | 大小 | 内容 | 可持久化 |
|------|:----------:|:----:|------|:--------:|
| SoftDevice | 0x00000 | 64KB | S132 协议栈保留 | - |
| 应用代码 | 0x10000 | ~384KB | 固件可执行代码 | - |
| 出厂信息区 | 0x70000 | 4KB | 出厂/结构信息(只读) | ✅ |
| 可写数据区 | 0x71000 | ~60KB | 曲线/日志/时钟/状态(可擦写) | ✅ |

> 具体地址以最终链接脚本（`.ld`）与实际烧录为准。

---

## 2. 出厂信息区（只读，烧录时写入）

> 对应接口契约 §4.3「泵特征/标识数据」。生产烧录时一次性写入，固件只读。

| 记录密钥 | 字段 | 类型 | 长度 | 说明 |
|----------|------|------|:----:|------|
| FI_MODEL | 泵型号 | char | 4 | 2字母+2数字 |
| FI_SERIAL | 唯一识别号 | char | 10 | 2字母+8数字 |
| FI_BT_PWD | 蓝牙密码 | char | 8 | 字母+数字 |
| FI_PROD_BATCH | 生产批号 | char | 10 | 8位日期+2字母 |
| FI_EXPIRY | 有效期 | char | 8 | 8位日期 |
| FI_FACTORY | 组装厂编号 | char | 2 | 2字母 |
| FI_MECH_MODEL | 机械模块型号 | char | 3 | 1字母+1数字+1字母 |
| FI_MECH_VENDOR | 机械供应商 | char | 3 | 1字母+2数字 |
| FI_MECH_BATCH | 机械批号 | char | 8 | 2字母+6数字 |
| FI_PCB_MODEL | PCB型号 | char | 8 | - |
| FI_PCB_VENDOR | PCB供应商 | char | 3 | - |
| FI_PCB_BATCH | PCB批号 | char | 8 | - |
| FI_MCU_MODEL | MCU型号 | char | 16 | nRF52832 |
| FI_MCU_ID | MCU唯一ID | char | 16 | FICR 读取 |
| FI_FW_VERSION | 固件版本 | char | 16 | e.g. "1.0.0" |

## 3. 可写数据区（可擦写，键值记录）

### 3.1 基础率曲线（48段）

| 记录密钥 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| BASAL_PROFILE | seg_count | uint8 | 段数(48) |
| BASAL_PROFILE | seg_rates[48] | float | 各段基础率(IU/h) |

- 首次绑定由 APP 下发，或替换曲线命令更新。

### 3.2 参数表（ICR/ISF等，可选持久化）

| 记录密钥 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| THER_ICR | hour_seg[24]+ratio[24] | - | 碳水化合物系数 |
| THER_ISF | hour_seg[24]+factor[24] | - | 胰岛素敏感系数 |

### 3.3 当前状态

| 记录密钥 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| CUR_STATE | pump_state | enum | 当前状态机状态 |
| CUR_STATE | last_pos | uint8 | 格栅物理序号 |
| CUR_STATE | reservoir_ml | float | 上次药量 |
| CUR_STATE | delivered_basal | float | 累计已注射基础率 |
| CUR_STATE | delivered_bolus | float | 累计已注射大剂量 |

### 3.4 时钟

| 记录密钥 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| RTC_LAST | datetime | uint32 | 最后校准时间戳 |
| RTC_DRIFT | drift_ppm | int16 | 校准时补偿 |

### 3.5 日志

| 记录密钥 | 字段 | 类型 | 说明 |
|----------|------|------|------|
| LOG_ENTRY_n | timestamp | uint32 | 事件时间戳 |
| LOG_ENTRY_n | event_code | uint16 | 事件码 |
| LOG_ENTRY_n | value | uint16 | 事件参数 |

- 环形缓冲，容量受限；支持 BLE 导出。

## 4. 存储一致性保障

| 机制 | 说明 |
|------|------|
| FDS 写前记录 | 掉电时最后一次写入仍可恢复 |
| 版本校验 | 每记录带版本号，供迁移 |
| CRC | 出厂信息区保存整个区 CRC，自检比对 |
| 单写者原则 | 同一记录密钥仅一个模块写，避免冲突 |

---

## 5. 与 APP 数据边界

- 固件只保存**泵运行必要数据**（曲线、状态、时钟、日志、出厂信息）；
- **不保存**患者个人信息、历史治疗统计、亲情号等 APP 侧数据（由 APP SQLite 保存）；
- 仅通过 BLE 契约暴露泵侧数据，双向通过《接口边界与契约文档》。

## 6. 容量估算

| 项 | 单条 | 数量 | 估算 |
|----|------|:----:|------|
| 基础率 | 48×float | 1 | ~200B |
| 参数表 | 24×float×2 | 1 | ~400B |
| 当前状态 | - | 1 | ~64B |
| 日志 | 8B | ≤800 | ~6.4KB |
| 出厂信息 | - | 1 | ~128B |

- 可写数据区总使用 <10KB，60KB 分区余量充足。
