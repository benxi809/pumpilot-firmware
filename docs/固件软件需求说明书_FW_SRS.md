## 1. 引言

### 1.1 目的
定义泵体固件的功能需求、技术参数、协议接口与安全要求，作为固件开发与确认测试的依据。

### 1.2 范围
固件运行于一次性贴敷式胰岛素泵的 nRF52832 MCU 上，负责：BLE 通信绑定、输注驱动与调度、药量/脉冲反馈监测、报警检测上报、时钟与日志、出厂信息管理。固件与 APP 之间唯一通道为 BLE(IEEE 11073)。

### 1.3 固件在系统中的地位
固件是**输注执行者**。APP 负责决策与命令下发（IU 剂量/基础率曲线），固件负责换算脉冲并物理执行，同时实时反馈状态与报警。

## 2. 固件功能需求

### 2.1 输注执行 (FW-DRIVE)

#### FW-DRIVE-01 微型步进电机驱动
- PWM1、PWM2 轮流输出 **20ms 宽脉冲**，间隔 **30ms**；
- 每脉冲转子转 **180°**，输注 **0.00339 IU**。

#### FW-DRIVE-02 基础率调度
- 48 段基础率（30分钟/段，24小时周期），设置单位 IU/h；
- 段总脉冲数 = `段基础率(IU/h) × 0.5 / 0.00339`；
- 每 **3 分钟**输注一次，将该段脉冲数按 3 分钟间隔分配执行，输注完成进入休眠；
- 计量小到不足每 3 分钟一次时按**均匀间隔**分配脉冲。

#### FW-DRIVE-03 大剂量执行
- **快速大剂量**：脉冲数 = `剂量(IU)/0.00339`，一次连续输出；
- **扩展大剂量**：指定时间内按基础率方式分布；
- **复合大剂量**：前半按快速(bolus)、后半按基础率方式分布；
- 切换点脉冲去重，防叠加（对应 APP 侧 RSK-04）。

#### FW-DRIVE-04 输注最小精度
- 最小增量 0.01 IU/h；最小输注量 0。

### 2.2 状态监测与反馈 (FW-SENSE)

#### FW-SENSE-01 滑动格栅药量
- 8×8 共 64 格，但**物理排列非按编号顺序**（蛇形/Z字扫描）。从活塞全推出（0ml）到完全回退（2ml）的实际排列次序为：
  `K7, K6, K5, K4, K3, K2, K1, K8, K9, K10, K11, K12, K13, K14, K15, K16, K17, K18, K19, K20, K21, K22, K23, K24, K32, K31, K30, K29, K28, K27, K26, K25, K41, K42, K43, K44, K45, K46, K47, K48, K40, K39, K38, K37, K36, K35, K34, K33, K49, K50, K51, K52, K53, K54, K55, K56, K56, K64, K63, K62, K61, K60, K59, K58, K57`
- **K7 = 0ml（药液用尽，一级报警）**；**K57 = 2ml（储药器灌满/满量）**；共 64 个物理位置。
- 药量换算须**依据上述物理排列序号→药量线性映射**（序号1=K7=0ml → 序号64=K57=2ml），**不可按格号数值直接相减**（K1 的编号虽小但物理位置在中段）。
- **K1 接通 = 剩余药液量低（二级报警）**（K1 物理排列在 0ml 端第 7 位）。

#### FW-SENSE-02 霍尔信号检测
- 每输出脉冲霍尔元件产生对应信号；
- 连续 10 个脉冲无霍尔信号 → **机械故障**（一级报警）。

#### FW-SENSE-03 阻塞检测
- 理论输注量超过滑动格栅值 **3.5 IU** → **管路堵塞**（一级报警）。

#### FW-SENSE-04 电池电量
- 电压 < 1.8V → 电池耗尽（一级）；
- 电压 < 2.0V → 电池电量低（二级）；
- < 2.0V 时第 37 管脚(ON/BYP)控制电源模块进入旁路模式，电池直接给 MCU 供电。

### 2.3 报警上报 (FW-ALM)

#### FW-ALM-01 报警上报
- 一级：管路堵塞、药液泄露、电池耗尽、药液用尽、自检出错、机械故障；
- 二级：泵电池电量低、剩余药液量低；
- 三级：系统时间误差过大、泵与 APP 失联超时。
- 报警信号**一旦产生立即上报**（不等待休眠周期）。

#### FW-ALM-02 报警驱动
- 一级泵端：短促连续脉冲震动/鸣叫，直到取下泵或电池耗尽；
- 二级：温和断续，30s 后休眠、30 分钟后再报，循环至应答；
- 三级：3 次温和，3 分钟后再报，循环至消除或应答。

### 2.4 通信 (FW-COMM)

#### FW-COMM-01 BLE 连接与绑定
- 使用二维码内的蓝牙连接密码鉴权；
- 首次与 APP 绑定后不再连接其他设备；
- 失联后只定向广播并可自动恢复与原绑定 APP 连接。

#### FW-COMM-02 IEEE 11073
- 遵循 IEEE 11073-20601 + 11073-10419；
- 提供**加密/公开**两种交互状态，出厂可选。

#### FW-COMM-03 数据同步
- 唤醒时执行与 APP 信息交换，平时保持呼吸连接；
- 基础率/ICR/ISF 表/大剂量数据接收与校验，返回接收结果；
- 控制命令确认并反馈执行结果。

### 2.5 时钟 (FW-CLOCK)

#### FW-CLOCK-01 时钟
- 连续时钟与世界时钟同步，日误差 ≤ 1s；
- 首次绑定由 APP 设置系统时间；
- 每小时与控制器对时（误差 >10 分钟报三级）。

### 2.6 设备出厂信息 (FW-INFO)

#### FW-INFO-01 出厂信息管理
- 存储并上报：泵型号、唯一识别号、生产批号、有效期、组装厂编号、泵结构信息（机械模块 + PCB 信息）、固件版本号；
- 出厂时一次性设定运行参数。

### 2.7 日志与能量 (FW-LOG / FW-PWR)

#### FW-LOG-01 日志
- 存储工作状态，可通过蓝牙导出。

#### FW-PWR-01 低功耗
- 正常工作 10 天（目标 2 周）低能耗；
- 仓储状态深度睡眠，灌注触发中断唤醒。

## 4. 协议对象模型（固件作为 agent）

固件需实现 IEEE 11073 对象模型（详见《接口边界与契约文档》§3.3），作为 agent 提供 MDS、各 Metric、PM-store、Schedule-store 等对象，使 APP(manager) 可读写。

## 5. 非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 驱动响应及时；脉冲调度在 3 分钟周期内完成 |

| 安全 | 绑定鉴权；加密交互；防误控 |
