## 1. 固件主流程（启动 + 事件循环）

```mermaid
flowchart TD
    A[上电/唤醒] --> B[时钟/电源初始化]
    B --> C[FlashStore 载入出厂信息]
    C --> D[GPIO_ISR 配置<br>灌注唤醒/霍尔/K65/K66]
    D --> E[SoftDevice 初始化 + BLE广播]
    E --> F[服务初始化<br>调度/监测/报警/日志]
    F --> G{泵状态}
    G -->|仓储| H[深睡等待灌注唤醒]
    G -->|初始休眠| I[等待贴敷+启用]
    G -->|就绪| J[进入事件循环]
    J --> K[等待事件队列]
    K --> M[分发处理事件]
    M --> K
```

## 2. 泵状态机（StateMachine）

```mermaid
stateDiagram-v2

    运行中 --> 废止: 废止
    治疗暂停 --> 废止: 废止
    运行中 --> 就绪: 输注停止
    仓储 --> [*]: 切除
    废止 --> [*]: 终止
```

## 3. 基础率调度（3分钟周期）

```mermaid
flowchart TD
    A[3分钟定时中断] --> B[计算当前时段 seg = now/30]
    B --> C[读段基础率 basal_table[seg]]
    C --> D[脉冲 = floor(seg_rate × 0.5 / 0.00339)]
    D --> E{余量累计 ≥ 1脉冲?}
    E -->|是| F[补发1脉冲<br>余量清零]
    E -->|否| G[保持余量]
    F --> H[PWM输出脉冲+霍尔校验]
    G --> I[累计已注射基础率]
    H --> I
    I --> J[更新FlashStore当前状态]
```

## 4. 大剂量调度（含复合双波切换）

```mermaid
flowchart TD
    A[接收 CMD_DELIVER_BOLUS] --> B{是否 fast/ext/dual?}
    B -->|fast| C[脉冲 = dose/0.00339]
    B -->|ext| D[按扩展时间匀距分布]
    B -->|dual| E[前半 bolus 连续输注]
    C --> F[PWM连续输出]
    D --> F
    E --> G{bolus 部分完成?}
    G -->|是| H{等待 pulse_busy=0<br>防叠加}
    H --> I[后半扩展部分匀距分布]
    H -->|叠加风险| J[阻塞新命令]
    F --> K[输注完成]
    G -->|否, 继续| E
    K --> L[更新状态/上报]
```

## 5. 药量监测（格栅蛇形映射）

```mermaid
flowchart TD
    A[GridScanner 扫描8×8矩阵] --> B[定位唯一接通键]
    B --> C[查蛇形物理次序表 grid_seq[64]]
    C --> D[物理序号 = index]
    D --> E[药量 = (序号-1)/63 × 2.0 ml]
    E --> F{位置判断}
    F -->|K7 接通| G[药液用尽 一级报警]
    F -->|K1 接通| H[药量低 二级报警]
    F -->|其他| I[正常状态]
    G --> J[上报+停止输注]
    H --> J
    I --> K[更新 ReservoirMonitor 状态]
```

## 6. 报警引擎（分级巡检）

```mermaid
flowchart TD
    A[周期巡检 AlarmEngine] --> B{电池电压}
    B -->|<1.8V| C[一级 耗尽 停止输注]
    B -->|<2.0V| D[二级 电量低]
    B -->|≥2.0V| E{理论 vs 格栅实测}
    E -->|差值>3.5IU| F[一级 堵塞 停止]
    E -->|正常| G{连续10脉冲无霍尔}
    G -->|是| H[一级 机械故障 停止]
    G -->|否| I{药液K7}
    I -->|是| J[一级 用尽 停止]
    I -->|否| K[正常]
    C --> L[触发蜂鸣+立即上报]
    D --> L
    F --> L
    H --> L
    J --> L
```

## 7. BLE 通信流（IEEE 11073 agent）

```mermaid
sequenceDiagram
    participant APP as APP (manager)
    participant GATT as GATT 180F (2A20/2A21)
    participant FW as 固件 IEEE11073 agent

    APP->>GATT: AssociateRequest
    GATT->>FW: 收到关联请求
    FW-->>GATT: AssociateResponse(accepted,密码校验)
    GATT-->>APP: 响应

    APP->>GATT: CMD_SET_TIME
    GATT->>FW: 时间同步
    FW-->>GATT: RPT_RESULT(ok)
    GATT-->>APP: 结果

    APP->>GATT: CMD_SET_BASAL(48段)
    GATT->>FW: 下发曲线
    FW-->>GATT: RPT_RESULT(received)
    GATT-->>APP: 接收确认

    APP->>GATT: CMD_DELIVER_BOLUS(op_id)
    GATT->>FW: 执行大剂量
    FW-->>GATT: RPT_WORK(执行中)
    GATT-->>APP: 工作状态
    FW--)GATT: RPT_ALERT 即时上报(报警时)
    GATT--)APP: 报警通知
```

## 8. 命令幂等处理（防重复输注）

```mermaid
flowchart TD
    A[接收命令] --> B{op_id 在缓存?}
    B -->|是,已执行| C[返回已执行结果<br>不重复执行]
    B -->|否| D[校验CRC/长度]
    D -->|失败| E[返回接收错误]
    D -->|成功| F[记录op_id到缓存]
    F --> G[执行命令]
    G --> H[返回执行结果]
```

## 9. 深度（事件）序列汇总

### 9.1 首次绑定时序
| 步骤 | 方向 | 内容 |
|:----:|:----:|------|
| 1 | APP→固件 | AssociateRequest(密码校验) |
| 2 | 固件→APP | AssociateResponse(accepted) |
| 3 | APP→固件 | CMD_SET_TIME |
| 4 | APP→固件 | CMD_SET_BASAL(48段) |
| 5 | APP→固件 | CMD_SET_PARAM |
| 6 | 固件→APP | RPT_RESULT(ok) |

### 9.2 异常路径清单
| 场景 | 处理 |
|------|------|
| 电池<1.8V | 一级耗尽 + 停止 |
| 堵塞 | 一级 + 停止 |
| 机械故障 | 一级 + 停止 |
| 药液用尽 K7 | 一级 + 停止 |
| 双波叠加 | 切换点等待缓冲清空 |
| 命令重复 op_id | 幂等去重 |
